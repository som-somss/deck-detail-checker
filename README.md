# DECK 상세도 자동 검토기 V6

V6 데크 제원 검토
1. 평면도(상면) 실제 폭/길이 ↔ 상세도 재료표 ↔ Excel 제원입력 비교
2. 단면 B-B의 실제 본체 두께 DIMENSION을 읽어 80 mm인지 확인 + Excel J열과 비교
3. TYPE별 `평면도 (하면)` 존재 여부로 데크 형식 판정
   - 있으면 일반형
   - 없으면 평판형
   - Excel P열 비고와 비교
4. 일반형의 평면도(하면)에서 CS-CONC-MINR 리브 외곽을 직접 찾아 리브 길이/수량 계산
   - Excel K열 리브 길이와 비교
   - Excel M열 리브 개수와 비교
5. 인식 실패는 O로 넘기지 않고 `확인` 표시

주의: 현재 리브 판독은 청람교/블루 상세도 양식의 실제 객체 구조를 기준으로 구현했습니다.
