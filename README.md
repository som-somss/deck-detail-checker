# DECK 상세도 자동 검토기 V16 테스트

이번 버전의 전단연결재 치수 비교 기준:

1. 평면도(상면) 좌·우측 치수 ↔ 단면 B-B 좌측 치수
   - 상면 좌측: 주 파형철선 Φ6 길이
   - 상면 우측: Φ5 길이(복수 길이 표기 지원)
   - B-B 좌측 치수와 대응 값 비교

2. 평면도(상면) 상·하측 치수 ↔ 단면 A-A
   - n@간격=합계 배치치수 비교
   - n×간격=합계 산술도 함께 검토
   - A-A 파형철선은 수직 실선 형상인지 별도 확인

3. 상면 Φ5/Φ6 ↔ 재료표
   - Φ5는 직접 Φ5 문자 표기 기준
   - 별도 Φ5 표기가 없는 주 파형철선은 Φ6
   - Φ5/Φ6 길이·수량은 재료표와 비교 대상으로 유지

화면:
- 세로 스크롤바
- X/확인 굵은 빨간 글씨
- TYPE 사이 구분선
