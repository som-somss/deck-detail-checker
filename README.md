# DECK 상세도 자동 검토기 V8

V7 기능을 유지하고 지금까지 합의한 전단연결재 검토를 추가했습니다.

## 유지 기능
- 평면도(상면) 실제 데크 폭·길이 ↔ 재료표 ↔ Excel
- 평면도(하면), 배근도(평면) 폭·길이 교차검토
- 두께는 80mm 고정값을 사용하지 않고 DXF 실제값 ↔ Excel 값 비교
- 평면도(하면) 존재 여부로 일반형/평판형 판정
- 리브 실제 길이/수량 ↔ Excel
- 단면 A-A 폭/두께
- 전단연결재/철근 간격 검토

## V8 추가
- 전단연결재 종류를 A-A / B-B / 전단연결재 상세 / 재료표 사이에서 교차검토
- 파형철선: 상면 점선, A-A 세로선 형태를 판별 기준으로 사용
- TRUSS GR: 상면 실선, A-A ∧형상, B-B 지그재그 형상을 판별 기준으로 사용
- TRUSS GR 직경을 Φ16으로 고정하지 않음. Φ12, Φ16 등 실제 표기를 읽어 비교
- TRUSS GR 높이를 125/135/150 등으로 고정하지 않음
- 전단연결재 상세 왼쪽 높이 치수 ↔ 재료표 높이 비교
- 파형철선 직경도 Φ5/Φ6 등 실제 표기를 읽어 비교

자동판독이 확정되지 않는 경우 임의로 O 처리하지 않고 `확인`으로 남깁니다.
