# DECK 상세도 자동 검토기 V7

기존 V6 기능 유지 + 다음 기능 추가

- 데크 두께: 80 mm 고정 기준 제거. DXF 상세도 실제 두께와 Excel 제원입력 두께가 같은지만 판정.
- 데크 폭·길이 교차검토:
  - 평면도(상면)
  - 평면도(하면): 일반형만
  - 배근도(평면)
  - 상세도 재료표
  - Excel 제원입력
- 단면 A-A:
  - 폭
  - 실제 본체 두께
  - 전단연결재 간격
  - 철근 간격
  - 전단연결재 종류
- 전단연결재 종류는 A-A의 파형철선/TRUSS GR 표기와 재료표 표기를 비교.
- 숫자를 억지로 추정하지 않도록 명시적 객체/치수를 찾지 못하면 `확인`으로 표시.

현재 자동판정 원칙:
- 전단연결재 간격은 `n@간격` 형태의 실제 DIMENSION을 평면도와 A-A에서 각각 찾아 비교.
- 철근 간격도 명시적 `@` 치수가 양쪽에서 모두 인식된 경우에만 O/X 자동판정.
- 단면 A-A 두께는 CS-CONC 단면 외곽에서 상면~본체 하단의 실제 형상 차이를 계산.
