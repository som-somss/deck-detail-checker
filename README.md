# DECK 상세도 자동 검토기 V11

전단연결재 종류 판정을 레이어/선종류 중심에서 실제 형상 중심으로 변경한 테스트 버전입니다.

## V11 종류 판정
- 단면 A-A
  - 반복되는 ∧/A 형상 → TRUSS GR
  - 전단연결재 위치의 반복 수직선 → 파형철선
- 단면 B-B
  - 연결된 삼각 지그재그 형상 → TRUSS GR
  - 파형철선은 형상 판독이 충분하지 않으면 임의 확정하지 않고 `확인`
- 전단연결재 상세
  - 연결된 삼각/트러스 형상을 실제 LINE 연결관계로 분석
- HAUNCH 같은 단순 경사선은 경사선 존재만으로 TRUSS로 판정하지 않음
- A-A/B-B/상세 중 2곳 이상에서 같은 종류가 확인되어야 O
- 서로 다른 종류로 판독되면 X
- 부족하면 확인

레이어명과 Linetype은 최종 종류 판정 기준으로 사용하지 않습니다.

기존 V10의 Φ5 끝단 55, 간격, 길이 관련 테스트 기능도 유지합니다.
