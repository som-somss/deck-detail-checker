# DECK 상세도 자동 검토기 V14

V14 수정사항
- 판정 `X`와 `확인`을 모두 굵은 빨간 글씨로 표시.
- Φ5 끝단 파형철선과 주 파형철선을 별도 항목으로 표시.
- 전단연결재 상세/재료표에서 Φ6가 실제 확인되면 `Φ6 파형철선 길이/수량`으로 표시.
- Φ6가 명시적으로 확인되지 않으면 임의로 Φ6라고 단정하지 않고 `주 전단연결재(파형철선)` + `확인`.
- `n@간격=합계`의 n은 간격 수이므로 주 연결재 수량은 n+1 EA.
- 전단연결재 길이는 주변 L= 값을 사용하지 않고 평면도(상면)/B-B의 지정 세로치수만 사용.
- Φ5는 끝단 55 위치와 대응 길이로 별도 검토.
- TYPE 구분선 유지.
