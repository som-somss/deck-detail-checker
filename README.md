# DECK 상세도 자동 검토기 V13

전단연결재 검토 로직을 정리한 버전입니다.

- V8~V12의 중복/오인식 전단연결재 종류 항목 제거
- 주변 `L=` 값을 전단연결재 길이로 사용하던 기존 항목 제거
- A-A: 수직 실선형=파형철선, ∧/A형=TRUSS GR
- B-B: 물결영역+`파형철선` 표기, 또는 삼각 지그재그/TRUSS 표기
- 전단연결재 상세도 함께 교차검토
- Φ5는 평면도(상면) 끝단 `55` 위치 수로 수량 판정
- 전단연결재 길이는 평면도(상면)의 좌/우 세로 치수와 B-B의 세로 치수만 후보로 사용
- `L=` 텍스트는 전단연결재 길이 판정에서 제외
- TYPE 구분선 및 `확인` 굵은 빨간글씨 유지

불확실한 길이 매핑은 임의로 O 처리하지 않고 `확인`으로 표시합니다.
