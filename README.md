# DECK 상세도 자동 검토기 V18 테스트

V17과 달리 화면에 보이는 치수 문자 위치만으로 방향을 판단하지 않습니다.

이번 버전:
- CAD의 DIMENSION 객체 정의점/연장선 위치를 읽음.
- 평면도(상면)의 실제 데크 외곽을 기준으로 위/아래/왼쪽/오른쪽 DIMENSION 분류.
- 사용자가 보여준 정렬 치수(Aligned Dimension), CZ-DIML 구조를 고려.
- 왼쪽 DIMENSION → Φ6 길이 후보.
- 오른쪽 DIMENSION → Φ5 길이 후보.
- 위/아래 n@간격 → A-A와 비교.
- 왼쪽/오른쪽 치수 → B-B 왼쪽과 비교.
- Φ5는 실제 Φ5 문자 표기 기준.
- X/확인 굵은 빨간색, 세로 스크롤바, TYPE 구분선 유지.

이 버전은 실제 결과를 보고 DIMENSION 정의점 분류가 맞는지 확인하기 위한 테스트 버전입니다.
