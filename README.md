# DECK 상세도 자동 검토기 V12

## 전단연결재 종류 판정 수정
A-A와 B-B에서 같은 모양을 찾지 않습니다. 각 뷰의 고유 형상을 각각 전단연결재 종류로 해석합니다.

- 단면 A-A
  - 반복되는 보라색 계열 수직 실선 형상 → 파형철선
  - 반복되는 ∧ / A 형상 → TRUSS GR
- 단면 B-B
  - 물결 형상과 좌측 `(파형철선)` 표기를 함께 참고 → 파형철선
  - 삼각 지그재그 형상 또는 `TRUSS GR` 표기 → TRUSS GR
- 전단연결재 상세
  - 상세 내부 종류 표기와 실제 트러스/파형 형상을 함께 참고
- 레이어명과 선종류는 최종 종류 판정 기준으로 사용하지 않음
- 각 뷰의 형상은 달라도, 판독된 '종류'가 서로 일치하는지 교차검토

## 화면 표시
- TYPE이 바뀔 때 굵은 구분선을 한 줄 삽입
- 판정이 `확인`인 항목은 굵은 빨간 글씨로 표시
