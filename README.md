# DECK 상세도 자동 검토기 V17 테스트

용어/방향 기준을 수정했습니다.

`상면`은 치수의 방향이 아니라 **평면도(상면) 배치 전체**를 뜻합니다.
프로그램은 평면도(상면)의 실제 외곽 형상을 먼저 찾고 그 주변을 네 영역으로 분리합니다.

- 평면도(상면)-위쪽
- 평면도(상면)-아래쪽
- 평면도(상면)-왼쪽
- 평면도(상면)-오른쪽

검토:
- 평면도(상면) 왼쪽·오른쪽 치수 ↔ 단면 B-B 왼쪽 치수
- 평면도(상면) 위쪽·아래쪽 배치치수 ↔ 단면 A-A
- A-A 파형철선 수직 실선 형상
- 평면도(상면) Φ5 직접 표기
- 평면도(상면) 왼쪽 세로치수 = Φ6 길이
- 평면도(상면) 오른쪽 세로치수 = Φ5 길이
- Φ5 표기가 없는 주 파형철선 = Φ6

화면 기능:
- 세로 스크롤바
- X/확인 굵은 빨간 글씨
- TYPE 구분선
