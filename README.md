# DECK 상세도 자동 검토기 V9 - 전단연결재 집중 테스트

철근 검토는 이번 단계에서 확장하지 않고, 전단연결재 검토를 우선 강화한 테스트 버전입니다.

## 반영
- 기존 V8 기능 유지
- 파형철선 / TRUSS GR 종류 교차검토
- 직경은 고정값 없이 실제 Φ 표기 판독
- TRUSS GR 높이는 고정값 없이 상세 왼쪽 치수 ↔ 재료표 비교
- A-A 간격 `n@간격=총길이` 검산
- `n@`는 수량이 아니라 간격 개수로 해석하고 연속배치 수량은 `n+1 EA`로 계산
  - 예: `3@280=840` → Φ6 연결재 4EA
- 양측 끝단 Φ5처럼 별도 배치되는 연결재는 별도 종류/직경 그룹으로 검토하도록 구조 확장
- 평면도(상면) 좌/우, 단면 B-B, 전단연결재 상세의 `L=` 길이 후보를 수집하여 교차검토
- 확정할 수 없는 종류/직경별 연결은 임의 O 처리하지 않고 `확인`

이번 버전은 전단연결재 길이/수량 매핑을 실제 샘플 결과로 조정하기 위한 테스트 버전입니다.
