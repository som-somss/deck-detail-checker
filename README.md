# DECK 상세도 자동 검토기 V19 테스트

확정 규칙:
- 평면도(상면) 오른쪽 치수 = Φ5 길이. 예: 1750(2000) → 1750×1EA + 2000×1EA.
- 평면도(상면) 왼쪽 치수 = Φ6 길이.
- 상부/하부 3@280=840 → Φ6 4EA.
- B-B에서는 수량을 다시 계산하지 않고, 상면에서 확정한 모든 길이가 B-B 좌측 치수에 존재하는지만 확인.
- A-A에서는 평면도(상면)의 상·하 배치치수를 비교하고 파형철선 수직 실선 형상을 확인.
- X/확인은 굵은 빨간색, 세로 스크롤바와 TYPE 구분선 유지.
