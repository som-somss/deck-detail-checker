# DECK 상세도 자동 검토기 V15

사용자 지정 전단연결재 검토 흐름 반영:
- 평면도(상면)에서 `Φ5` 문자가 직접 붙은 전단연결재만 Φ5.
- 별도 Φ5 표기가 없는 주 파형철선은 Φ6.
- 좌측 세로치수 = Φ6 길이.
- 우측 세로치수 = Φ5 길이. `1750(2,000)`처럼 복수 길이 지원.
- `3@280=840`은 3간격 → Φ6 4EA.
- B-B에 상면에서 확인한 Φ5/Φ6 길이가 모두 존재하는지 교차검토.
- A-A에서 파형철선이 수직 실선 형상인지 확인.
- A-A의 n@간격=합계와 상면 배치를 비교하고 산술도 검사.
- 재료표 Φ5/Φ6 길이별 수량 비교용 결과행 추가.
- 기존 55→Φ5 판정 제거.
- 세로 스크롤바 추가.
- `X`와 `확인`은 굵은 빨간 글씨.
- TYPE 사이 구분선 유지.

불확실한 재료표 길이별 매핑은 임의로 O 처리하지 않고 `확인`으로 남깁니다.
